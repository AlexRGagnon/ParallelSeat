# ADR-0006: User-mode MVP before bridge or driver

## Context
Bridge/driver add security and maintenance cost.

## Decision
Prove logical-seat model in user mode with harness before any injection or WDK work.

## Alternatives
Driver-first — rejected.

## Consequences
Phases 9–10 gated by G7/G8.

## Validation
G0–G6 complete before bridge/driver justification.
