# Verification Gates

| Gate | Meaning |
|------|---------|
| G0 | Technical assumptions, ADRs, experiments defined; .NET 8 SDK available |
| G1 | Same-process shared-state harness proven |
| G2 | Independent AI overlay proven |
| G3 | Background semantic actions proven |
| G4 | Strict no-focus-steal routing proven |
| G5 | Python-controlled seat lifecycle proven |
| G6 | Human-priority conflict handling proven |
| G7 | First real application compatibility classified |
| G8 | Bridge or driver work justified or rejected |

No phase proceeds past a failed gate without architecture revision.
